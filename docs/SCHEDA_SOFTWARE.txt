NOME SOFTWARE
  moVeer (iOS)

DESCRIZIONE IDENTIFICATIVA
  Applicazione mobile di analisi biomeccanica basata sull'intelligenza
  artificiale. MoVeer analizza video di esecuzione di esercizi fisici,
  valuta tecnica e postura dell'atleta, individua errori di esecuzione
  e genera un report dettagliato con punteggio, diagramma corporeo
  dello stress articolare, correzioni mirate ed esercizi correttivi
  personalizzati. Il software integra dati di profondità nativi
  (LiDAR/ToF) e sensori wearable Bluetooth (frequenza cardiaca) per
  un'analisi più precisa, e include un agente AI Mentore che guida
  l'utente prima, durante e dopo ogni esercizio. Il software è rivolto
  ad atleti, personal trainer e appassionati di fitness che desiderano
  migliorare la qualità del movimento e prevenire infortuni articolari.

LINGUAGGIO DI PROGRAMMAZIONE
  Frontend:  JavaScript (React 18 + Vite)
  Stile:     Tailwind CSS + shadcn/ui (Radix UI)
  Backend:   Supabase BaaS (Auth, PostgreSQL, Storage, Edge Functions)
  Database:  PostgreSQL con Row Level Security (RLS)
  Integrazioni IA: Gemini API per analisi vision, biomechanics engine,
             agente AI in-app con accesso RLS al catalogo e ai report
  Native:    Plugin Capacitor (@moVeerAI/depth-scanner) per acquisizione
             dati di profondita LiDAR/ToF (Swift/ARKit per iOS,
             Kotlin/ARCore per Android); helper depth3d.ts per il
             calcolo di angoli articolari 3D reali
  Wearable:  Web Bluetooth API per fascia cardio esterna (GATT service
             0x180D); libreria wearableSensors.js per parsing e
             aggregazione dati fisiologici
  Piattaforma: frontend web sul dominio proprietario + backend Supabase;
               shell native iOS/Android da configurare separatamente

NOTE TECNICHE
  - Architettura single-page application (SPA) con routing lato client
  - Layout responsive mobile-first con safe-area iOS (notch/home indicator)
  - Autenticazione gestita da Supabase Auth (email/password, Google OAuth, OTP)
  - Tabelle PostgreSQL: exercises, analysis_reports, athletes, profiles,
    user_entitlements, mentor_conversations, mentor_messages
  - Catalogo previsto: 691 esercizi, 14 macro-categorie; export dati non
    incluso nel repository e da importare nel progetto Supabase
  - Funzioni Edge: analyzeExercise (analisi IA con supporto depth 3D
    e dati wearable), deleteOwnAccount, sendUserReport (inoltro
    segnalazioni utenti via email agli admin), notifyAthleteReport
    (notifica email automatica all'atleta a nuovo report pronto, solo
    piani a pagamento Pro/Coach), suggestCorrectiveExercises (suggerisce
    esercizi di correzione mirati dal catalogo in base ai difetti di
    postura rilevati nel report)
  - Agente AI Mentore: chat conversazionale con accesso RLS al catalogo
    e ai report, guida tecnica
    personalizzata sull'esecuzione degli esercizi
  - Integrazione sensori wearable: fascia cardio Bluetooth esterna,
    dati fisiologici (frequenza cardiaca) correlati alla qualità tecnica
  - Export report in PDF (jsPDF) con diagramma corporeo SVG
  - Acquisizione video: CameraRecorder RGB (web); import depth JSON
    LiDAR/ToF, visualizzazione 3D nei report; plugin Android incompleto
  - Salvataggio video registrati sul dispositivo (download locale)
  - Calcolo biomeccanico deterministico dello stress articolare basato su
    profili di movimento pattern-specifici (incluso pattern ciclismo)
  - Gestione atleti: entita Athlete con pagine Athletes e AthleteDetail;
    selezione atleta in Analyze con propagazione genere al report
  - Sistema di monetizzazione: pagina Monetization (admin-only) con
    export PDF, pagina Subscription, campo plan su User, piani
    Free/Coach/Pro con limiti di utilizzo
  - Sicurezza admin: campi blocked/role su User, AuthContext guard per
    account bloccati, pagina Users per gestione admin, FeedbackDialog
    con funzione sendUserReport per segnalazioni via email
  - Architettura offline-first: cache locale report (reportCache.js)
    con fallback a dati cached in assenza di connessione
  - Pagine pubbliche: About e Contact (PublicLayout) accessibili senza
    autenticazione; documenti legali (Termini d'uso, Privacy & Policy)
  - Catalogo esercizi: 691 esercizi su 14 macro-categorie (Forza,
    Powerlifting, Body Building, Calisthenics, Corpo Libero, Cardio,
    Mobilita, Funzionale, Ciclismo, Camminata, Corsa, Kettlebell,
    Posturali, Riabilitazione); attrezzatura normalizzata in 11 categorie
  - Dashboard progressi: ReportsProgressDashboard con KPI cards e grafici
    recharts (punteggio, postura, potenza) integrato nella pagina Reports
  - Branding personalizzato: campo logo_url su User, LogoUploader per
    upload logo personale (piano Pro/Coach), logo renderizzato nell'header
    dei report a schermo e nei PDF esportati
  - Upload media su Supabase Storage; report e punti depth in PostgreSQL
  - Ricerca e filtri atleti: Athletes.jsx con ricerca testuale (nome/note)
    e filtro per genere via useMemo, contatore risultati e reset filtri
  - Notifica automatica atleti: campo email su Athlete, funzione backend
    notifyAthleteReport che invia email all'atleta quando un nuovo report
    è pronto (punteggio ed esercizio), limitata ai piani a pagamento
    (Pro/Coach); chiamata non bloccante da Analyze.jsx dopo la creazione
    del report
  - Suggerimento esercizi correttivi mirati: funzione backend
    suggestCorrectiveExercises che analizza i difetti di postura del
    report e seleziona dal catalogo (categorie Riabilitazione/Mobilità/
    Posturali/Corpo Libero/Funzionale) fino a 5 esercizi pertinenti via
    LLM; componente CorrectiveExerciseSuggestions integrato in
    ReportDetail con card cliccabili che linkano al dettaglio esercizio
